# Changelog

## 0.1.0 — 2026-10-23

Initial public release.

- Native floating Windows pill for physical RAM and disk storage or transfer speed.
- Compact layout that fits one or both metrics and preserves the widget's center.
- Expanded RAM, disk read/write, and selected-drive capacity details.
- Green/yellow/red thresholds with explanations on hover.
- Tray icon with background monitoring, visibility controls, and quit action.
- Dark settings window with live preview, drive selection, refresh interval, and saved preferences.
- Original logo, portable executable, Windows CI, smoke tests, and release packaging.
